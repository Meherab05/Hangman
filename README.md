# Hangman (C, iGraphics)

A simple Hangman game built in C using the iGraphics library. Developed as a project for **Structured Programming (L-1 T-1)** at BUET.

## Features

- Basic Hangman gameplay  
- Graphical UI with iGraphics  
- Background music  
- Score leaderboard  

## Files & Folders

- `iMain.cpp` – Main source file  
- `iMain.exe` – Windows executable  
- `bmp/` – Image assets  
- `music/` – Background music  
- `leaderboard.txt` – Stores scores  
- `iGraphics.h`, `stb_image.h`, `glut32.dll` – Required libraries

## How to Run

1. Open `iMain.cpp` in a C IDE (e.g. Code::Blocks).  
2. Keep all files/folders in the same directory.  
3. Build and run.

Or just run `iMain.exe` (Windows only).

## Note

Make sure `glut32.dll` is in the project folder or `C:\Windows\System32`.
